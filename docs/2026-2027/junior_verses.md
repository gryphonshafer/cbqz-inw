# 2026-2027 Junior Quizzing Verse List

Junior Quizzing uses a smaller selection of Memory Verses, and a selection of Story Verses that do not need to be memorized but can have queries asked about them. Some verses are in both lists. Below is the list of verses that will be asked for the 2026-2027 season.

There is a printable [Memory Verse Chart](/john_junior_quizzing_memory_verse_chart.pdf) and [Coloring Sheet](/john_junior_quizzing_coloring_sheet.pdf) — both perfect for hanging on refrigerators.
